# KrydderGutta.eb — statisk nettside

Dette er en enkel statisk nettside for KrydderGutta.eb som viser to produkter:
- Super Sur Mixs — 100 kr
- Fredagsdip — inspirert av Holiday Dip

Filer:
- `index.html` — hovedsiden
- `styles.css` — enkel styling

Hvordan bruke:
1. Legg filene i repoet ditt (f.eks. i rotmappen).
2. Åpne `index.html` i nettleseren for å forhåndsvise.
3. For å publisere: bruk GitHub Pages (Settings → Pages) eller et annet hosting-tilbud.
